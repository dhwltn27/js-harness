# 보안 검토와 처리

값은 출력하지 않고 파일:줄, 열 이름, 건수만 쓴다. `.env` 같은 비밀 파일은 열지 않는다.

## 1. 찾기 (읽기 전용)
- 비밀 파일 후보: `.env*`(`.env.example` 제외), `*.key`, `*.pem`, `config/*secret*`, `credentials*`.
- git 추적 여부와 이력: `git ls-files`, `git log --all --name-only --format=`로 이름만 확인한다.
- 코드·설정의 비밀 후보: `password`, `secret`, `token`, `api_key` 같은 이름 옆에 실제 값이 대입된 곳, 긴 무작위 문자열. `git grep -n -I`로 찾되 출력은 파일:줄만 남긴다. 환경변수 이름만 있는 줄은 후보에서 뺀다.
- 개인정보: 이름, 사번, 연락처, 이메일로 보이는 열이나 필드, 자유 텍스트 안의 개인정보, 합치면 사람을 알아볼 수 있는 열 조합. 결과 파일, 로그, 오류 메시지, 테스트 데이터, 중간 파일에 들어가는지.
- 가린 처리: 해시, base64 같은 인코딩, 일부만 자르기로 바꾼 값은 가린 것으로 치지 않는다. 집계 결과는 몇 건 안 되는 그룹(5건 미만)으로 사람이 드러나지 않는지 본다.
- 요청자 답(공유 범위, 사람 정보 허용, 원본·중간 파일 허용)과 다르게 처리된 곳.
- 이번 작업 중 원본 행이나 개인정보 값을 출력한 명령이 있었는지 돌아보고, 있으면 알린다.
- 찾은 범위(파일 종류, 폴더, git 이력 포함 여부)를 적어 둔다.

찾은 결과를 위치 / 종류 / 판정(실패, 통과와 이유) / 처리 제안 표로 보이고, 처리할지 사용자에게 묻는다.

## 2. 처리 (사용자 확인 후)
- 비밀 파일이 추적 중이면: `.gitignore`에 추가하고 `git rm --cached <파일>`로 추적만 해제한다. 파일은 지우지 않는다.
- 이미 예전 저장 기록에 들어 있으면 이력을 고쳐 쓰지 않는다. 결정 기록 "보안"에 "추적 해제함, 과거 이력에는 남아 있음, 값 교체가 필요함"을 적고 요청자에게 알릴 문장 2줄을 만든다.
- 코드에 값이 박혀 있으면 환경변수로 읽게 바꾸고, 필요하면 값 없는 `.env.example`만 둔다.
- 개인정보는 결과물 약속(README, 요청자 답)이 허락한 범위만 남긴다. 가릴 때는 지우거나 집계한다. 답이 없으면 요청자 질문으로 올리고, 그 사이에는 공유 결과와 로그에 넣지 않는다. 약속이 요구하는 열을 임의로 빼지 않는다.

## 3. 확인
- 1번 찾기를 다시 돌려 숫자로 보인다: 추적 중 비밀 파일, 실제 값이 드러난 비밀, 허락 범위 밖 개인정보 노출. 각각 0이 목표다.
- 0으로 만들 수 없는 것(과거 이력 등)은 남은 한계로 적는다.

## 출력
위치 / 종류 / 처리 / 남은 한계 표 하나.
